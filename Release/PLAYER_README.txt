THE GOD WHO WAS FORGOTTEN — WINDOWS PLAYER

This package is a {{VERSION}} work-in-progress build of the Avarsha and Agniya Act I
slice. It is not the finished campaign. The exact source commit, Unity version
and build variant are recorded in build-info.txt beside the game.

INSTALL AND START

1. Extract the entire ZIP into a folder you can write to.
2. Keep TheGodWhoWasForgotten.exe and its _Data folder together.
3. Run TheGodWhoWasForgotten.exe. Unity Editor is not required.
4. Choose New Game at the Main Menu. Continue loads an existing save.

This is a Windows x64 build. Minimum hardware requirements have not yet been
established by the planned performance pass; 1080p at 60 FPS on an Intel 14th
generation Core i7 and NVIDIA RTX 4060 is a target, not a measured guarantee.

CONTROLS AND SAVES

See CONTROLS.txt for keyboard, mouse and gamepad bindings. The in-game Controls
screen shows the current bindings and offers remapping. Save from the pause
menu. Game saves are stored in your Windows user profile under:

AppData\LocalLow\DefaultCompany\The God Who Was Forgotten\Saves

If a new build has trouble with an existing save, keep a copy of that folder
when reporting the problem. The automated build checks scene travel and a save
loaded in a second process, but the full Release playthrough is pending.
